Coffman Conditions for Deadlock

A deadlock occurs if and only if all 4 conditions hold: Mutual Exclusion, Hold & Wait, No Preemption, and Circular Wait.

Wait-For Graph (WFG) Principle

A simplified variant of Resource Allocation Graph (RAG) where vertices are processes and directed edge \(V_i \to V_j\) signifies that \(V_i\) is blocked waiting for \(V_j\) to release a resource.

3-Color DFS Cycle Algorithm

Vertices are labeled WHITE (unvisited), GRAY (on active recursion stack), or BLACK (visited). An edge encountered pointing to a GRAY vertex constitutes a back-edge, proving a directed cycle!

Automated Preemption Recovery

The resolution engine selects a victim VM in the cycle and breaks its wait dependency, preempting its allocation to restore the system to an acyclic safe state.

🎓 BCA Viva & Academic Architecture Reference Guide

Key viva questions, concepts, and architectural explanations for project defense

BCA Project Viva

☕ OOP & Architecture (Model-DAO-Service-Controller)

Q: Explain the Model-DAO-Service-Controller architecture used in CloudShield.
- Model: Pure Java POJO beans (User, Resource, VirtualMachine) encapsulating entities with private attributes and getters/setters.
- DAO: Data Access Objects (UserDAO, AllocationDAO) using JDBC PreparedStatements for safe database operations.
- Service: Business logic layer (DeadlockDetector, ThreatDetector, SecurityManager) implementing algorithms independently of UI.
- Controller: REST API controller (ApiController, CloudShieldServlet) dispatching JSON HTTP requests.
Q: How are OOP principles applied in this project?
- Encapsulation: Private variables in models accessed solely through validated getters/setters.
- Abstraction: Services hide complex graph algorithms (DFS) and cryptographic hashing behind clean method signatures.
- Single Responsibility: Each DAO manages exactly one database table.

🔄 Operating Systems & Deadlock Detection

Q: What is a Wait-For Graph (WFG) and how is it used here?
In OS theory, a Wait-For Graph is a directed graph where vertices are processes (Virtual Machines) and edges denote that process A is waiting for a resource held by process B. For single-unit resources, a cycle in the WFG is both a necessary and sufficient condition for a deadlock.
Q: How does the DFS Cycle Detection algorithm work?
We implement a 3-Color DFS traversal (WHITE/GRAY/BLACK). When an edge is traversed to an already GRAY vertex (currently on the recursion call stack), a back-edge is identified, proving the existence of a circular wait condition.

🛡️ Cybersecurity & Threat Defense

Q: How does CloudShield protect against SQL Injection?
All database queries use PreparedStatement with parameter placeholders (?). The database driver treats user input strictly as literal values rather than executable SQL syntax.
Q: How is brute-force authentication prevented?
Every login is tracked in login_logs. If 3 consecutive failed login attempts occur, the account is automatically locked (account_status = 'BLOCKED') and a CRITICAL alert is logged.

🗄️ Database & PostgreSQL Features

Q: How are ACID transactions implemented in Java JDBC?
In AllocationDAO.java, we invoke connection.setAutoCommit(false). We lock the resource row (FOR UPDATE), verify availability, deduct balance, insert allocation, and invoke connection.commit(). If any failure occurs, connection.rollback() restores consistency.
Q: What database constraints and triggers are utilized?
- CHECK constraints: Enforce non-negative resource balances and valid statuses.
- FOREIGN KEYS: Ensure referential integrity with cascading deletes.
- TRIGGERS: Automated lockout trigger (trg_login_security) and VM state sync.
